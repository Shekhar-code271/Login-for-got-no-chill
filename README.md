# 🤪 Login "for got no chill"

An insanely over-engineered, interactive Rube Goldberg machine form built with vanilla **HTML**, **CSS**, **SVG**, and powered by **GSAP (GreenSock Animation Platform)**[cite: 7, 8, 9]. 

Forget standard form validation—here, interacting with input fields, checkboxes, and buttons triggers a massive mechanical chain reaction featuring spinning gears, mechanical sprayers, counterweights, and lowering cars!

## ✨ Features

* **Complex Mechanical Animations:** Built entirely with advanced GSAP timelines that orchestrate synchronised movements across a web of SVG components.
* **Interactive Form Logic:**
  * **Name Validation:** Entering a valid name sets off a gear-driven mechanical sprayer system[cite: 8].
  * **Email Validation:** Typing a valid email triggers a complex weight-drop, spiral winding system, and lowers a miniature car onto a scale[cite: 8].
  * **Checkbox & Submit Interaction:** Checking agreement boxes and interacting with the submit button pulls timing chains and dynamic cable connectors[cite: 8].
* **Responsive Scaling:** Includes automatic window resizing and scale-to-fit logic for the central container[cite: 8].
* **Pure Tech Stack:** Built with plain HTML, CSS, SVG, and GSAP v3 (loaded via CDN)[cite: 7, 8, 9].
